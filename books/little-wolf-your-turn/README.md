# 小狼，換你說！

一本為 7–9 歲、小二至小三讀者設計的繁體中文原創「犬」部首故事繪本。小狼在森林故事會被安排演壞蛋，卻想演提燈送朋友回家的好鄰居。朋友們聽見他的想法，也開始說出自己的角色願望。

## 成品

- `exports/小狼，換你說！_繪本.pdf`：34 個單頁，包含封面、32 內頁、封底。
- `exports/小狼，換你說！_跨頁閱讀版.pdf`：18 個畫面，適合橫向閱讀及課堂投影，保留跨頁節奏。
- `exports/小狼，換你說！_可編輯排版.pptx`：18 張原生排版投影片；正文、書名、生字、頁碼與圖像均可分別選取和修改，並非整頁截圖。
- `editable/`：18 份 SVG 排版檔，連結至同專案的插畫，適合 Inkscape 等向量排版工具。
- `exports/全書縮圖.png`：全書版面總覽。

正文約 367 個漢字，14 個故事跨頁；六個核心字為「狗、狐、狸、狼、猴、獅」，延伸「猜、獨」，兼認「犬／犭」與反犬旁。字目在故事中自然重複，書末設部首遊戲。

## 編輯方法

開啟 PowerPoint 或 SVG 前，安裝 `assets/fonts/Iansui-Regular.ttf`，避免電腦以其他字型替代而改變版面；授權見同資料夾 `OFL.txt`。PDF 已嵌入實際使用的字型，閱讀時不需安裝。

PPTX 中的圖像是可替換的原創插畫物件，文字是原生可編輯文字；插畫本身不是可逐筆拆解的向量。SVG 可修改排版和文字，也可替換連結的 PNG。請連同 `assets/` 一起保存，維持檔案相對路徑。

`story.json` 是故事、分鏡、字目、角色和配色的主要編輯來源。改動後可重建三種成品；插畫原檔保留於 `assets/illustrations/`，角色設定圖為 `assets/characters.png`，生成提示與參考關係記錄於 `artwork-log.json`。PDF 採高品質圖像壓縮，原始 PNG 不改動；這是數位閱讀成品，沒有宣稱已完成印廠 CMYK／300dpi 製版。

```sh
python3 -m pip install -r requirements-book.txt
python3 build_book.py
```

依賴版本固定於 `requirements-book.txt`。內部校稿圖輸出在忽略提交的 `.cache/`；正式交付都在 `exports/` 和 `editable/`。頁碼採左偶、右奇；扉頁為第 1 頁，故事第 2–29 頁，部首遊戲第 30–31 頁，製作頁第 32 頁。

## 參考與教學

兩本參考繪本的藝術、版面、語言及閱讀節奏分析，見 `design-brief.md`。它們是使用者提供的參考閱讀；沒有把原書圖像、角色或故事移作新書插圖，也沒有將兩份參考 PDF 放入公開專案。

建議先完整讀故事，再看書末字目。可問孩子：

1. 小狼有甚麼話還沒說？從耳朵、手和坐的位置找線索。
2. 小狗做了甚麼，讓朋友們開始說自己的願望？
3. 演戲時扮演壞蛋，就表示演員本人是壞人嗎？角色可以嘗試，也可以表達自己的選擇。
4. 你想設計甚麼新角色？用一個犬部字寫一句話，畫在新的角色卡上。

部首教學留意：不是所有犬部字都指動物，故事中的「猜、獨」就是延伸例子；本書採「狐狸」的犬旁「狸」，不替換成豸旁「貍」。繁體「貓」是豸部，「豬」是豕部，不套用簡體「猫、猪」的分類。
