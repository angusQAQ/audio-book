# 本書字型

一般文字使用芫荽 Iansui，沿用專案原樣字型：

- https://github.com/ButTaiwan/iansui
- https://raw.githubusercontent.com/google/fonts/main/ofl/iansui/Iansui-Regular.ttf
- 原授權與作者資訊見 `OFL.txt`。

走部字目使用芫茜雅楷 JyunsaiKaai Bold，覆蓋「走、起、趕、超、越、趟、趣、趁」，在正文中以 1.5 倍字級強調：

- https://github.com/ItMarki/jyunsaikaai
- https://raw.githubusercontent.com/ItMarki/jyunsaikaai/main/fonts/JyunsaiKaai-Bold.ttf
- 字型名稱表與上游 README 均明示 SIL OFL 1.1；保留未修改的 TTF、上游 README，以及 `JyunsaiKaai-OFL.txt` 內的作者／商標資訊和完整授權。
- 完整 SIL OFL 文本來源：https://raw.githubusercontent.com/spdx/license-list-data/main/text/OFL-1.1.txt

上游以貼近香港教育字形為方向，亦明示尚未全部調整。本書使用其清楚的手寫楷體筆意及完整字目涵蓋，不宣稱獲官方認證。PDF 嵌入實際使用字形；編輯 PowerPoint／SVG 前應安裝這兩個字型檔。
