# 走！去找那朵雲

為 7–9 歲、小二至小三自主閱讀設計的繁體中文原創走部故事繪本。阿米和小澄去找天上的白兔雲；一個趕着走，一個留意腳邊，最後在水窪發現另一種天空。

核心字為「起、趕、超、越、趟、趣」，兼認「走」、延伸「趁」。正文 359 個漢字、14 個故事跨頁。圖像採灰鉛筆及局部色鉛筆、大留白，字目使用完整涵蓋八字的手寫楷體，正文為一般文字的 150%。

- `exports/走！去找那朵雲_跨頁閱讀版.pdf`：18 畫面，保留圖文跨頁節奏，適合投影。
- `exports/走！去找那朵雲_可編輯排版.pptx`：18 張原生文字／獨立插圖物件的 PowerPoint。
- `editable/`：18 個 SVG，連結同專案插畫，可用 Inkscape 編輯。
- `story.json`：故事、字目、分鏡、角色和配色；`design-brief.md`：參考書細讀與編輯取捨。
- `assets/`：角色模型表、15 幅正式插畫、未修改字型及授權；生成來源與提示另存紀錄。

## 編輯與重建

開啟 PowerPoint 或 SVG 前，安裝 `assets/fonts/Iansui-Regular.ttf`、`assets/fonts/JyunsaiKaai-Bold.ttf`，避免替代字型改變字形及版面。PDF 已嵌字，閱讀時不用安裝。文字、字目、頁碼及圖像物件可分別修改；插畫為獨立 PNG，並非可逐筆拆解的向量。

```sh
python3 -m pip install -r requirements-book.txt
python3 build_book.py
```

內部排版校稿使用 `--proof`，輸出於不提交的 `.cache/proof/`；正式模式不容許缺少封面或任一插畫。依賴版本固定；排版驗證同時核對 PDF 可見文字、中縫、PPTX 文字與字體／大小，以及 SVG 結構。這是數位閱讀版，未宣稱完成實體印廠製版。

## 閱讀與教學

先完整讀故事，再整理部首。可請孩子說：

1. 小澄在看甚麼？阿米最初有沒有看見？
2. 為甚麼小水窪裏有「大魚」？圖中甚麼讓你知道它是雲的倒影？
3. 開頭和結尾說同一句話，阿米的心情和做法有甚麼不同？
4. 「有趣」一定是指走路嗎？再在生活中找一個走部字。

書末字卡答案為「趕」；跑是足部，追是辵部，不能因意思相近而混列。故事不把快與慢當成好壞標籤，也不把孩子的想像說成科學定義。
