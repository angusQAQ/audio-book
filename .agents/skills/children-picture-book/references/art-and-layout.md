# 插畫與版面製作

## 本書的美術設定

依需求設計角色，不預置前作人物。角色模型表記錄年齡外觀、髮型、服裝、配色、身高比例、左右手、攜帶道具及表情範圍；非人類角色或無字書依題材調整。場景、道具與核心視覺線索也記錄一致規則。

先用文字與小草圖決定圖文空間，再生成角色模型表和全書插畫。使用可用的影像生成／編輯工具；若有 `image_gen`，以它處理生成及插畫修訂。需要編輯的本地圖先實際查看，傳入正確參考；透明圖明確指定透明背景。精確中文文字由排版工具加入，不要求影像模型畫好整頁文字。

逐頁提示包含本書媒材、角色／場景、動作、鏡頭、道具數量、文字留白及中縫安全區。參考本書角色圖以保持一致，保存每次精確提示、工具／來源識別、參考、原圖與 SHA-256。修改只影響有問題的圖，舊版留在 revisions 或 Git 歷史，不重寫原始生成紀錄。

每次檢查人物、衣着、左右方向、肢體、道具數量、前後空間及圖文含義；文字說倒影時，圖不能畫成真的魚。角色有改名而圖中無姓名字樣時，更新故事／替代文字即可，不必重繪。

## 共用版面來源

將正文與繪圖分離，建立資料驅動的頁面項目，例如原生文字、獨立插圖、線條、色塊。用實際字型度量計算字寬、基線、行高與字距，輸出 PDF、PPTX 及 SVG 共用同一組位置。

排版依本書年齡、閱讀裝置與方向決定尺寸及字級；不要套用固定尺寸、頁數、邊界或字型。正文、標題、活動字卡有清晰層次。臉、文字、重要道具避免落在中縫及裁切邊；字幕、頁碼與圖像也要保持空間。

## 字體、字目與專名號

- 逐字檢查所有使用字型的 cmap，不以「看起來像手寫」取代缺字檢查。新增姓名及生字也要檢查。
- 保留字型原檔、授權與來源，PDF 嵌入實際字型。不要假稱官方教育字體認證。
- 只有本書要求字目強調時，設定目標字集合、字型、比例及粗細；可採手寫體放大，但比例應由本次需求決定。
- 一般文字與放大字共用基線並重算行高、換行及字距；放大後再檢查圖文重疊，不只改 CSS 或字級。
- 要求人名專名號時，使用完整人名下方的連續細直線，避開標點與相鄰文字。姓名視為不可拆行單位，線條與字形留有間距，不用 Unicode 組合底線破壞原文。
- PDF／SVG 的線條按姓名實際字寬計算；PowerPoint 可採原生底線或將可編輯線條與原生文字編組，實際開啟驗證。移除工具主題自帶陰影。
- 字體、姓名長度、內容或字級變更後重算標記位置，同步所有輸出；若有點讀，再同步點擊範圍與音訊。

## 校稿方法

全書渲染縮圖檢查節奏與一致性，再檢查每頁的高解析輸出。至少放大最密集文字、最大字目、姓名專名號、臉靠中縫、封面及活動頁。

按需使用 ReportLab／PyMuPDF 生成與檢查 PDF、python-pptx 製作可編輯 PowerPoint、SVG／Inkscape 製作向量排版、LibreOffice 開啟驗證。它們是可選工具，不是限制所有專案必須使用的產品。

確認 Office 或向量工具沒有替代字型、改變換行、添加陰影或移動圖片；用程式核對文字與幾何位置，用實際畫面核對可讀性與圖文含義。不得僅憑檔案存在或程式退出碼聲稱排版完成。
