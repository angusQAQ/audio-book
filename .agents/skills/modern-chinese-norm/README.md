# 現代漢語規範 skill

本技能由使用者提供，已安裝在點點書房專案的 `.agents/skills/modern-chinese-norm/`。`SKILL.md` 與 `reference.md` 按附件原文保存；來源、檔案大小及SHA-256見 `source.json`。介面描述另見 `agents/openai.yaml`。

在本專案可使用 `$modern-chinese-norm`。中文文案校訂時先讀兩份文件，按主幹、修飾語、搭配、語序、指代、邏輯與歧義逐句判斷；純句子糾錯使用原句／語病／修正三項。涉及書稿、下載品或網站修改時，仍須完成所要求的實際檔案、驗證、Git存檔及發布，交付成品連結。

繪本使用繁體中文與規範書面語，依已確認的讀者程度調整句長和詞彙；香港課程術語、指定食物名稱、人物姓名及粵語讀音按本次要求保留。需結合上下文區分句法錯誤、事實問題、用詞選擇及合理的擬人／省略；排版文件中表示font的「字型」依其技術含義使用。

這次安裝範圍為本repository。附件中關於跨專案或所有對話的適用描述屬於原檔內容；其他專案須按其環境另行安裝。繪本製作另依 `../children-picture-book/SKILL.md` 執行。
