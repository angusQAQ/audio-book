# 現代漢語結構：判斷細則

體系取 LCH2184「現代漢語結構」的語病分類，句法框架對齊黃伯榮、廖序東《現代漢語》。下面只留判斷時要用的操作標準。

## 診斷順序

1. 標出分句。複句先看第一層關係，再往下切。
2. 每個分句抽出主幹。主幹不成話，先定是搭配不當還是成分殘缺。
3. 主幹成話，再查定語、狀語、補語、聯合短語和關聯詞。
4. 主幹和枝葉都成話，再查邏輯、指代和歧義。

## 搭配不當

- 主謂：「旅客向郊野深度遊轉型。」轉型的主語是模式、產業，不是人。
- 動賓：「豐富提高了技術水準。」一個動詞接不上這個賓語。
- 主賓：「香港的人口密度是世界上最高的城市之一。」主語是密度，賓語是城市。
- 修飾語和中心語：「達到好水平。」水平用「高、低」衡量。
- 聯合項：「冒著滂沱大雨和泥濘的道路。」「冒著」只能管「大雨」。
- 關聯詞：「因為……，反而……。」因果不跟「反而」配。常套是：因為……所以……；雖然……但是……；只要……就……；只有……才……；無論……都……；不但……而且……；與其……不如……；即使……也……。

## 成分殘缺

- 介詞吞主語：「通過這次交易，使我知道了方法。」刪「通過」或刪「使」，留下一個主語。
- 時間狀語吞主語：「教師講授的時候，可以通過圖像幫助學生。」改成「教師在講授的時候，可以……」。
- 缺謂語：「甲班和乙班羽毛球比賽。」補「進行」一類動詞。
- 缺賓語：「作出每天只能上網一個小時。」補「規定」一類中心語。
- 缺關聯詞：「不僅體色像竹子，體形像樹枝。」後一分句補「而且」。

「基於學生知識較弱，未必能夠理解……」這類句子，主語只出現在狀語裡，主句要補回「他們」。

## 成分贅餘

同義成分只留一個：「主要……為主」「極之十分」「其他別的」「錯誤……不正確」「大約一百多」「正在……了」。

「少量課堂活動為主」同時是贅餘和自相矛盾：既說少量，又說這是主體。

## 語序不當

定語由大到小、由領屬到性質：領屬、指示、數量、形容、不帶「的」的名詞。多層狀語：時間、處所、範圍、情態、對象。

- 「讓全班同學首先朗讀。」「首先」若是教師的步驟，放在「讓」前。
- 「不但甲能……，而且……。」遞進的兩項若是同一主語的兩個謂語，關聯詞放在主語後：「甲不但……，而且……。」兩項主語不同，關聯詞放在各自主語前。
- 分句順序跟時間、因果、遞進一致。先有的、程度低的在前。

## 句式雜糅

兩套都能說，就選一套，不可各截一段：

- 「關鍵在於服務態度起決定作用。」留「關鍵在於服務態度」或「服務態度起決定作用」。
- 「靠的是利用電磁力來實現的。」留「靠的是電磁力」或「是利用電磁力來實現的」。
- 「理解可以如何描寫。」留「理解如何描寫」或「知道可以如何描寫」。
- 「是哪一天，共借出多少本。」只問一項。日期若只是條件，改成定語：「借閱最多的那天共借出多少本。」

## 用詞不當

- 形容詞誤作動詞：「美觀家居」改「美化家居」。
- 詞義不合：「千鈞一髮的機會」改「千載難逢的機會」。
- 代詞無先行詞，或「他告訴他」分不出誰。提問用「哪些」，回指已知事物用「這些」。
- 「我需要學生繪畫。」「需要」不等於「讓、請、要求」。
- 動態助詞「了」不跟「正在」連用。連謂結構裡，「過」放在後一個動詞上：「進教室讀過書」，不說「進過教室讀書」；「搬上了山頂」，不說「搬了上山頂」。

## 邏輯錯誤

- 自相矛盾：「慢慢地迅速着陸」「斷定他大概會」「大約一百多位」。
- 種屬並列：「各種生物和魚類」。魚類已在生物裡。
- 主客或範圍不一致：前文說「面容」，後文用「身體外貌」去接同一個對象。

## 歧義

一個謂語能接兩個主語，而句意只允許一個時，寫明主語。「邀請學生分享作品，並且親自描述」裡，「親自」可以屬「我」，也可以屬「學生」。改成「並請他們描述」。

## 港式中文改標準中文

用戶沒有要求保留港式中文時，按下表改。左欄不出現在標準中文回覆裡。

| 港式 | 標準中文 |
| --- | --- |
| 送王先生出門先 | 先送王先生出門 |
| 賺多點／講少一句 | 多賺點／少說一句 |
| 一天好過一天 | 一天比一天好 |
| 送一輛車他 | 送他一輛車 |
| 是時候談談這件事 | 是談談這件事的時候了 |
| 現在是適當時候推行計劃 | 現在是推行計劃的適當時候 |
| 從選擇上要注重創新 | 在選擇上要注重創新 |
| 從保護中長大 | 在保護中長大 |
| 對談判帶來難度 | 給談判帶來難度 |
| 進過教室讀書 | 進教室讀過書 |
| 租了給另一戶 | 租給了另一戶 |
| 搬了上山頂 | 搬上了山頂 |

粵語用字（嘅、咗、喺、佢、唔、咩、點解）不進入標準中文。對應寫成的、了、在、他、不、什麼、為什麼。

同形詞先按標準中文詞義理解，再決定用不用：港式「認真」常指不馬虎，「下班」的「班」在港式裡可以指班次，「打尖」在港式裡常指插隊。標準中文回覆不用這些港式詞義。

## 定中和總括

- 「『走』部首的漢字」「『走』部件漢字」定中不完整。寫成「以『走』為部首的漢字」「以『走』為部件的漢字」。
- 「用來學習這些漢字競賽遊戲」少一個「的」，會讀成學習遊戲本身。應是「用來學習這些漢字的競賽遊戲」。
- 總括語緊接並列項：「眼睛、鼻子、嘴巴、臉形這四個選項。」不要寫成「……臉，四個選項。」逗號會把總括語拆成沒有謂語的殘句。
- 兩個「的」可以各管一個中心語：「你最喜歡的玩偶的樣子。」不要為了少一個「的」去改合法結構。

## 聯合項和雙賓

- 後補語只能管能搭配的那一項：「把字詞拖到玩偶身上，也可以點擊這些字詞。」不要寫「拖動或點擊字詞到玩偶身上」。
- 「給予」的雙賓是「給予某人某物」：「給予學生三分鐘。」「給予三分鐘時間學生完成練習」是「給予學生時間」和「讓學生完成」雜糅。
- 「安排幾位同學為一組」會把每位同學說成一組。應是「把同學分成小組，每組三至四人」。

## 容易誤用的詞

| 不當 | 規範 |
| --- | --- |
| 一併朗讀 | 一起朗讀。一併是順便連同別的事 |
| 字型 | 字形。字型指字體樣式 |
| 接送一位學生到2B | 接一位學生到2B。接送是來回 |
| 課堂開始之初 | 課堂開始的時候。開始和之初重複 |
| 再次重申 | 重申 |
| 每個主題分別進行 | 每個主題進行。每個和分別重複 |
| 我需要學生繪畫 | 我讓學生繪畫 |
| 採用朋輩協助 | 採用朋輩協助的方式 |
| 撰寫句子 | 寫出句子。撰寫多接文章、報告 |
| 詞彙構造畫面 | 詞彙形成畫面 |
| 氛圍兩個版本 | 分為兩個版本。氛圍是名詞 |
| 在中國是一個姓氏 | 是一個中國姓氏 |

「能夠」把事情說成已經做得到。「能否」才是問做不做得對：「觀察學生能否選出。」「是否能夠理解」用來評估時可以保留。

## 前後要對上

同一對象只用一個名稱。前句是「漢字」，後句不要改成「字詞」。前句總結成「段落」，後句不要說朗讀「這個句子」。前句是「畫好的玩偶」，後句不要改成「自己設計的玩偶」。比較的兩項要對齊：初階說難度和字數，高階也說難度和字數。

「而且」只連接同類情況。專注力低和「部分學生是非華語學生」不是同一類，不要用「而且」硬接，也不要再加「因此」推出全班語文能力低。

## 不必改的句子

選擇問句「校服、體育服、長裙還是西裝」成立，「還是」放在最後一項前。時間名詞可以直接作狀語：「課堂總結期間，教師需要提問。」「試一試用這些詞語描述」是合法連動。主幹、枝葉、關聯都成立時，修正照錄原句。
