# 現代漢語結構規範

凡回覆裡有中文，先按本規範寫完，再送出。不在回覆裡宣告「已檢查語法」。

規範對象是要給人讀的中文：說明、教案、工作紙、題目、介面文案、註釋、文件。程式識別名、既有專有名詞、用戶指定要保留的原句，不改寫。

字形跟用戶來稿。用戶用繁體就回繁體，用簡體就回簡體。未指定時用繁體。

默認寫標準中文（A級書面語）：普通話語法，詞語用現代漢語通語。用戶明確要求粵語、港式中文或保留口語時，才偏離。

## 送出前

逐句做，不要只看通順：

1. 抽出主幹（主語、謂語、賓語）。看主謂、動賓、主賓能否搭配。
2. 查定語、狀語、補語跟中心語。聯合短語的每一項都要能跟同一個成分搭配。
3. 看主語在不在主句上。介詞「在、對、通過、由於、基於、經過」不可把主語套進狀語，令後面的分句沒有主語。
4. 關聯詞要成對，位置跟分句主語對齊。一組關係只用一套關聯詞。
5. 同一個意思只用一種句式。兩套說法粘在一起，先拆開再留一套。
6. 同義成分不疊用。代詞要有先行詞。「那些」指已知事物，「哪些」才用來提問。
7. 前後概念範圍一致，不自相矛盾，不把種概念和屬概念並列。同一個對象前後只用一個名稱。
8. 聯合短語後面的補語、賓語，要能同時管到每一項。
9. 港式語序改回標準中文。高頻句式和詞語對照見 [reference.md](reference.md)。

改完再讀一次主幹。仍有上述問題，先改再送出。

## 八類必改

判定標準和例句見 [reference.md](reference.md)。

| 類型 | 送出前要攔住的樣子 |
| --- | --- |
| 搭配不當 | 主語、謂語、賓語、修飾語、聯合項，有一項接不上 |
| 成分殘缺 | 缺主語、謂語、賓語、必要的定語／狀語／關聯詞 |
| 成分贅餘 | 同義詞疊用，或定語、狀語、賓語多餘 |
| 語序不當 | 定語、狀語、關聯詞、分句次序錯位 |
| 句式雜糅 | 兩種句式各取一半 |
| 用詞不當 | 詞性用錯、詞義用錯、代詞無所指、虛詞用錯 |
| 邏輯錯誤 | 自相矛盾、分類不當、主客顛倒 |
| 歧義 | 一個成分能接兩個主語或兩個中心語，而上下文分不開 |

## 不要誤改

下面這些是合法結構，沒有別的錯誤就保留：

- 主謂謂語句：「這件事，我認為有問題。」
- 「因為」分句已有主語，「所以」分句承前省略主語。
- 主語清楚的流水句，逗號連接即可，不必硬加連詞。
- 教學術語和課程既有說法（如小學語境的「本科」指這一科、「簡報」指投影片）在該語境中清楚時，不改成另一個詞。

## 改病句時的回覆

用戶交出句子，要求指出語病或改成規範中文時，只回這三項，不加別的段落：

```
原句：
語病：
修正：
```

「語病」最多三句，點明類型和錯在哪個成分。多處錯誤併進這三句，不逐條展開成講義。「修正」給改完的整句或整段，意思跟原句對齊，不順手改寫風格。原句沒有語病時，語病欄說明主幹為何成立，修正欄照錄原句。用戶要求改成某一年級能讀的題目，或要求段落語意順暢時，仍用這三項，並在修正裡完成。
