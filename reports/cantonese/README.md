# 粵語正音查核

依使用者要求，以香港中文大學《漢語多功能字庫》為依據：<https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/>。

`worksheets/` 每列是一個實際點讀位置，保留書名 ID、閱讀畫面、文字區、句／詞／字模式、原文、朗讀文字及上下文。共 4,437 個有聲音的點讀位置；不是把同一字形全部合成一列，因此可為多音字按語境選讀法。`reviewKey` 包含上下文，不能把另一個語境的核准結果誤套進來。

`selectedJyutping` 初始留空，`status` 初始為待查核；不可把未核對的自動推測填成已核准。填入讀音時須查官方條目、核對詞義，並為姓名、生字、部首名稱和異讀記錄選擇依據。`reviewer` 和 `notes` 用來記錄實際校音結果。`language=en` 為原書英語內容，保留原語言朗讀，不硬配粵拼。

`cuhk-lookup.json` 由 GitHub 工作流程實際查詢後才產生，保存候選音、來源網址、來源頁雜湊及所屬上下文；候選擷取成功也不是正音批准。若官方頁面或網絡不可用，記錄阻礙，不拿另一份字典冒充中大來源。工具不把整個字庫的解釋或錄音重新發布為本專案素材。

聲線試音另見 `voice-review/mei-school/`（實際生成後才出現）。VoxCPM 試音與 Whisper 轉寫均保留為待聽校狀態。語音的字音、聲調、漏讀／加字與音質都核對後，再對新音檔取得實際對齊時間；原 Edge 時間不能沿用，也不能平均切分。

重建工具為 `scripts/prepare_cantonese_review.py`；若已有查核表，它會拒絕覆寫，避免刪掉人工決定。新版本需要比對上下文後合併，不能悄悄清空核准紀錄。
